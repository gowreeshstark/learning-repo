# Docker Network

## Network types

- **Bridge**: default bridge network.
- **None**: if used, only the container is created and it will not be accessible over the network.
- **Host**: accessible only within the host; it cannot be accessed over a separate network.

## Main concepts

### Bridge network

- Supports **port forwarding**.
- Every container can reach other containers inside the same bridge network.

### Useful commands

```bash
sudo docker network ls
sudo docker network create --help
```

### Custom networks

- You can create your own network with a customized IP range.
- Create a new bridge network:

```bash
sudo docker network create my_network
```

- Create a network with a custom subnet:

```bash
sudo docker network create --driver bridge --subnet 172.18.0.0/16 my_network
```

- To check the IP range of a network, use:

```bash
sudo docker network inspect <network-name>
```

### Using a custom network with a container

- Create a container and attach it to the network:

```bash
sudo docker run -d --name my_container --network my_network nginx
```

- You can also connect an existing container to a network:

```bash
sudo docker network connect my_network <container-name>
```

### Container access

- You can connect to a container within the host using the container's IP and port.
- To get the IP, use:

```bash
docker container inspect <container-name>
```
