# Docker Commands Reference

A comprehensive guide to commonly used Docker commands for managing containers and images.

---

## Container Management

### Run a Container
```bash
docker run [OPTIONS] IMAGE [COMMAND]
```
Creates and starts a new container from an image.

**Common options:**
- `-d` - Run in detached mode (background)
- `-it` - Interactive terminal
- `-p HOST_PORT:CONTAINER_PORT` - Port mapping
- `-v HOST_PATH:CONTAINER_PATH` - Volume mounting
- `--name NAME` - Assign a name to the container
- `-e VAR=VALUE` - Set environment variables

### List Containers
```bash
docker ps          # List running containers
docker ps -a       # List all containers (running and stopped)
```

### View Container Logs
```bash
docker logs CONTAINER_ID
docker logs -f CONTAINER_ID    # Follow logs in real-time
```

### Stop a Container
```bash
docker stop CONTAINER_ID
docker stop $(docker ps -q)    # Stop all running containers
```

### Start a Container
```bash
docker start CONTAINER_ID
```

### Remove a Container
```bash
docker rm CONTAINER_ID
docker rm $(docker ps -aq)     # Remove all containers
```

### Execute Command in Running Container
```bash
docker exec -it CONTAINER_ID COMMAND
docker exec -it CONTAINER_ID bash    # Open bash shell
```

### View Container Details
```bash
docker inspect CONTAINER_ID
```

### View Container Resource Usage
```bash
docker stats CONTAINER_ID
```

## Image Management

### Build an Image
```bash
docker build -t IMAGE_NAME:TAG .
docker build -t IMAGE_NAME:TAG -f Dockerfile .
```

### List Images
```bash
docker images
docker images -a       # Include intermediate images
```

### Pull an Image
```bash
docker pull IMAGE_NAME
docker pull IMAGE_NAME:TAG
```

### Push an Image
```bash
docker push REGISTRY/IMAGE_NAME:TAG
```

### Remove an Image
```bash
docker rmi IMAGE_ID
docker rmi IMAGE_NAME:TAG
docker image prune     # Remove unused images
```

### Tag an Image
```bash
docker tag SOURCE_IMAGE:TAG TARGET_IMAGE:TAG
```

### View Image Details
```bash
docker inspect IMAGE_ID
```

### Save Image to File
```bash
docker save IMAGE_NAME > IMAGE_NAME.tar
```

### Load Image from File
```bash
docker load < IMAGE_NAME.tar
```

## Volume Management

### Create a Volume
```bash
docker volume create VOLUME_NAME
```

### List Volumes
```bash
docker volume ls
```

### Remove a Volume
```bash
docker volume rm VOLUME_NAME
docker volume prune     # Remove unused volumes
```

### Inspect a Volume
```bash
docker volume inspect VOLUME_NAME
```

## Network Management

### List Networks
```bash
docker network ls
```

### Create a Network
```bash
docker network create NETWORK_NAME
```

### Connect Container to Network
```bash
docker network connect NETWORK_NAME CONTAINER_ID
```

### Disconnect Container from Network
```bash
docker network disconnect NETWORK_NAME CONTAINER_ID
```

### Inspect Network
```bash
docker network inspect NETWORK_NAME
```

### Remove a Network
```bash
docker network rm NETWORK_NAME
```

## Docker Compose

### Start Services
```bash
docker-compose up
docker-compose up -d    # Run in background
```

### Stop Services
```bash
docker-compose down
```

### View Services Status
```bash
docker-compose ps
```

### View Service Logs
```bash
docker-compose logs
docker-compose logs -f SERVICE_NAME    # Follow logs
```

### Execute Command in Service
```bash
docker-compose exec SERVICE_NAME COMMAND
```

### Rebuild Services
```bash
docker-compose up --build
```

## System Management

### Display Docker Info
```bash
docker info
```

### Show Docker Version
```bash
docker version
```

### View System-wide Information
```bash
docker system df          # Show disk usage
docker system prune       # Remove unused data
```

### Clean Up Resources
```bash
docker container prune    # Remove stopped containers
docker image prune        # Remove unused images
docker volume prune       # Remove unused volumes
docker network prune      # Remove unused networks
```

## Useful Tips

| Command | Purpose |
|---------|---------|
| `docker ps --format "table {{.ID}}\t{{.Image}}\t{{.Status}}"` | Custom container listing |
| `docker rename OLD_NAME NEW_NAME` | Rename a container |
| `docker cp FILE CONTAINER:/PATH` | Copy file to container |
| `docker cp CONTAINER:/PATH FILE` | Copy file from container |
| `docker pause CONTAINER_ID` | Pause a container |
| `docker unpause CONTAINER_ID` | Resume a paused container |

## Common Workflows

### Build and Run
```bash
docker build -t myapp:1.0 .
docker run -d -p 8080:3000 --name myapp-container myapp:1.0
```

### Debug Container
```bash
docker exec -it myapp-container bash
```

### View Logs
```bash
docker logs -f myapp-container
```

### Clean Up Everything
```bash
docker system prune -a
```
