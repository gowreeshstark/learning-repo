# Docker Containers

## Core Concept

The fundamental workflow of containerization:

```
BUILD → SHIP → RUN (anywhere)
```

---

## What is Containerization?

Containerization is a lightweight virtualization technology with the following characteristics:

- **Lightweight virtualization** - More efficient than traditional VMs
- **Bundled dependencies** - Applications packaged with all necessary binaries and libraries
- **Portability** - Run consistently anywhere the runtime is available
- **Isolated environments** - Complete isolation with all required dependencies
- **Build once, run anywhere** - Easy build and deployment across environments

---

## Virtualization vs Containers

### Traditional Virtualization
- Multiple operating systems run on top of the hypervisor
- Each VM has its own complete OS
- Heavier resource consumption

### Containers
- Hosted on a single machine sharing the **same kernel** across all containers
- Each container has its own isolated filesystem and environment
- Lightweight and efficient
- Failure in one container doesn't affect others
- Install Docker to host and manage containers

---

## Key Advantages

✅ Isolation between containers
✅ Efficient resource usage
✅ Easy deployment and scaling
✅ Consistent behavior across environments
