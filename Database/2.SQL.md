# SQL in DBMS - Complete Fundamentals with Examples

## 1) What is SQL?

**SQL (Structured Query Language)** is the standard language used to create, read, update, and manage data in relational databases (RDBMS) such as MySQL, PostgreSQL, SQL Server, and Oracle.

## 2) SQL Command Categories (Important Concept You Missed)

### DDL (Data Definition Language)
Used to define and modify structure.
- `CREATE` - Used to create new table
- `ALTER` - Used to add, delete, or modify columns in an existing table.
    - `Add` column - Adds a new column to a table
    - `Drop` column - Deletes a column in a table
    - `Rename` column - Renames a column
    - `Modify` column - Changes the data type, size, or constraints of a column
    - `dd` constraint - Adds a new constraint
    - `Rename` table - Renames a table
- `DROP` - used to permanently delete an existing SQL database/table
    - `DROP TABLE TABLENAME`
    - `DROP DATABASE DB`
- `TRUNCATE` - Used to quickly remove all rows from a table while keeping its structure, constraints, and indexes intact. It is faster than DELETE without a WHERE clause because it deallocates data pages instead of logging each row deletion.

```sql
CREATE TABLE Employee (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(100) NOT NULL,
    salary DECIMAL(10,2)
);

ALTER TABLE Employee ADD COLUMN department VARCHAR(50);
```

### DML (Data Manipulation Language)
Used to modify data.
- `INSERT`
- `UPDATE`
- `DELETE`

```sql
INSERT INTO Employee (emp_id, emp_name, salary, department)
VALUES (1, 'Anu', 60000, 'Engineering');

UPDATE Employee
SET salary = 65000
WHERE emp_id = 1;

DELETE FROM Employee
WHERE emp_id = 1;
```

### DQL (Data Query Language)
Used to read data.
- `SELECT`

### DCL (Data Control Language)
Used for permissions.
- `GRANT` - Assign privileges to a user This command allows a user to perform specific actions on database objects such as tables, views, or procedures
- `REVOKE` - Remove privileges from a user This command withdraws previously granted permissions, restricting the user’s access.

### TCL (Transaction Control Language)
Used to manage transactions.
- `COMMIT`
- `ROLLBACK`
- `SAVEPOINT`

## 3) Basic SQL (Mentioned Topics)

Assume this table:

`Employee(emp_id, emp_name, department, salary, join_date)`

### SELECT
```sql
SELECT emp_id, emp_name, salary
FROM Employee;
```

### WHERE
```sql
SELECT *
FROM Employee
WHERE department = 'Engineering';
```

### ORDER BY
```sql
SELECT emp_name, salary
FROM Employee
ORDER BY salary DESC;
```

### GROUP BY
```sql
SELECT department, COUNT(*) AS total_employees
FROM Employee
GROUP BY department;
```

### HAVING
```sql
SELECT department, AVG(salary) AS avg_salary
FROM Employee
GROUP BY department
HAVING AVG(salary) > 50000;
```

### LIMIT
```sql
SELECT *
FROM Employee
ORDER BY salary DESC
LIMIT 5;
```

## 4) Joins (Mentioned Topics)

Assume tables:
- `Employee(emp_id, emp_name, dept_id, manager_id)`
- `Department(dept_id, dept_name)`

### INNER JOIN
Returns matching rows from both tables.
```sql
SELECT e.emp_name, d.dept_name
FROM Employee e
INNER JOIN Department d ON e.dept_id = d.dept_id;
```

### LEFT JOIN
All rows from left table + matches from right.
```sql
SELECT e.emp_name, d.dept_name
FROM Employee e
LEFT JOIN Department d ON e.dept_id = d.dept_id;
```

### RIGHT JOIN
All rows from right table + matches from left.
```sql
SELECT e.emp_name, d.dept_name
FROM Employee e
RIGHT JOIN Department d ON e.dept_id = d.dept_id;
```

### FULL OUTER JOIN
All rows from both tables (matched + unmatched).
```sql
SELECT e.emp_name, d.dept_name
FROM Employee e
FULL OUTER JOIN Department d ON e.dept_id = d.dept_id;
```

### SELF JOIN
Join a table with itself.
```sql
SELECT e.emp_name AS employee, m.emp_name AS manager
FROM Employee e
LEFT JOIN Employee m ON e.manager_id = m.emp_id;
```

### CROSS JOIN
Cartesian product of both tables.
```sql
SELECT e.emp_name, d.dept_name
FROM Employee e
CROSS JOIN Department d;
```

## 5) Subqueries (Mentioned Topic)

### Subquery in WHERE
```sql
SELECT emp_name, salary
FROM Employee
WHERE salary > (
    SELECT AVG(salary) FROM Employee
);
```

### Subquery in FROM
```sql
SELECT dept_summary.department, dept_summary.avg_salary
FROM (
    SELECT department, AVG(salary) AS avg_salary
    FROM Employee
    GROUP BY department
) dept_summary;
```

### Correlated Subquery
```sql
SELECT e1.emp_name, e1.salary
FROM Employee e1
WHERE e1.salary > (
    SELECT AVG(e2.salary)
    FROM Employee e2
    WHERE e2.department = e1.department
);
```

## 6) CTE (Mentioned Topic)

**CTE (Common Table Expression)** improves readability for complex queries.

```sql
WITH DeptSalary AS (
    SELECT department, AVG(salary) AS avg_salary
    FROM Employee
    GROUP BY department
)
SELECT e.emp_name, e.department, ds.avg_salary
FROM Employee e
JOIN DeptSalary ds ON e.department = ds.department
WHERE e.salary > ds.avg_salary;
```

### Recursive CTE (Important Concept You Missed)
Useful for hierarchical data (employee-manager tree, category tree).

```sql
WITH RECURSIVE OrgChart AS (
    SELECT emp_id, emp_name, manager_id, 1 AS lvl
    FROM Employee
    WHERE manager_id IS NULL

    UNION ALL

    SELECT e.emp_id, e.emp_name, e.manager_id, o.lvl + 1
    FROM Employee e
    JOIN OrgChart o ON e.manager_id = o.emp_id
)
SELECT * FROM OrgChart;
```

## 7) Window Functions (Mentioned Topic)

Window functions perform calculations across a set of rows related to current row.

### ROW_NUMBER()
ROW_NUMBER() is a window function in SQL that assigns a unique sequential integer to rows within a partition of a result set. 
It starts counting from 1 for each partition and increments by 1 for each row.

Syntax:
ROW_NUMBER() OVER (PARTITION BY column ORDER BY column)

Common use cases:
- Ranking rows within groups
- Finding the first or last occurrence in each group
- Removing duplicates
- Pagination
```sql
SELECT emp_name, department, salary,
             ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) AS row_num
FROM Employee;
```

### RANK()
The RANK() function assigns a rank to each row based on the specified ORDER BY clause. If multiple rows have the same value, they receive the same rank, and the next rank is skipped. For example, if two rows tie for rank 1, the next row is ranked 3, not 2

```sql
SELECT emp_name, department, salary,
             RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS salary_rank
FROM Employee;
```

### DENSE_RANK()
The DENSE_RANK() function is similar to RANK(), but it does not skip ranks after ties. Tied rows receive the same rank, and the next rank continues sequentially. This is useful when a continuous ranking sequence is required 

```sql
SELECT emp_name, department, salary,
             DENSE_RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS dense_rank_num
FROM Employee;
```

### LEAD()
Returns the value from a subsequent (next) row.
```sql
SELECT emp_name, salary,
             LEAD(salary) OVER (ORDER BY salary) AS next_salary
FROM Employee;
```

### LAG()
Returns the value from a previous row.
```sql
SELECT emp_name, salary,
             LAG(salary) OVER (ORDER BY salary) AS previous_salary
FROM Employee;
```

### PARTITION BY
Groups rows into partitions for window calculations.

```sql
SELECT emp_name, department, salary,
             AVG(salary) OVER (PARTITION BY department) AS dept_avg_salary
FROM Employee;
```

## 8) Constraints (Important Concept You Missed)

Constraints enforce data quality.

- `PRIMARY KEY`
- `FOREIGN KEY`
- `UNIQUE`
- `NOT NULL`
- `CHECK`
- `DEFAULT`

```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    amount DECIMAL(10,2) CHECK (amount > 0),
    order_status VARCHAR(20) DEFAULT 'PENDING',
    UNIQUE (order_id, customer_id)
);
```

## 9) Views (Important Concept You Missed)

A **View** is a virtual table based on a query.

```sql
CREATE VIEW HighPaidEmployees AS
SELECT emp_id, emp_name, department, salary
FROM Employee
WHERE salary > 70000;

SELECT * FROM HighPaidEmployees;
```

Benefits:
- Simplifies repeated queries
- Adds abstraction/security

## 11) Real-Time Practice Query (All-in-One)

**Problem:** Get top 2 highest-paid employees from each department with department average salary, and only show departments having at least 3 employees.

```sql
WITH DeptStats AS (
    SELECT department,
                 COUNT(*) AS emp_count,
                 AVG(salary) AS dept_avg_salary
    FROM Employee
    GROUP BY department
    HAVING COUNT(*) >= 3
), RankedEmp AS (
    SELECT emp_id, emp_name, department, salary,
                 DENSE_RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS rnk
    FROM Employee
)
SELECT r.emp_id, r.emp_name, r.department, r.salary, d.dept_avg_salary
FROM RankedEmp r
JOIN DeptStats d ON r.department = d.department
WHERE r.rnk <= 2
ORDER BY r.department, r.salary DESC;
```
